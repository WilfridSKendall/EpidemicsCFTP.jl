# Maintaining `FigureUtilities`

Create the local package
```julia
using Pkg
Pkg.develop(path="/home/wilfrid/ms/PerfectEpidemics/julia/FigureUtilities")
Pkg.build("FigureUtilities")
```

Add a symbolic link to directory ./FigureUtilities
```julia
] dev ./EpidemicsCFTP	
] dev ./FigureUtilities
```

Invoke in script using
```julia
using FigureUtilities
```

Note we need to add packages such as `Colors` as a formal dependency of FigureUtilities
in Manifest.toml. Within the directory do
```julia
activate .
add Colors, Compose, DataFrames, Measures, Cairo, Fontconfig, Gadfly, InteractiveUtils
dev EpidemicsCFTP
```

## Recompilation of module
Try 
```julia
force_recompile(package_name::String) = Base.compilecache(Base.identify_package(package_name))
force_recompile("FigureUtilities")
```
(But this is now one of the tasks carried out by `make clean`.)
