Testing FreeEpidemic
====================
Here are invocations of the 'FreeEpidemic' and 'Innovations' classes::

     >>> from pprint import pprint
     >>> from epidemic import Innovations, FreeEpidemic
     
     >>> iv = Innovations(remove=[[1, 1.6], [1.3], [0.5, 2]],
     ...                  infect=[[[0.4, 0.9], [0.6, 1.4]],
     ...                          [[0.2, 1.1, 1.5]]])

     >>> print(str(iv))
     [[1, 1.6], [1.3], [0.5, 2]]
     [[[0.4, 0.9], [0.6, 1.4]], [[0.2, 1.1, 1.5]]]

     >>> epidemic = FreeEpidemic(innovations=iv)
     >>> pprint(epidemic())
     [(0, (2, 1, 0)),
      (0.2, (1, 2, 0)),
      (0.4, (0, 3, 0)),
      (0.5, (0, 2, 1)),
      (1, (0, 1, 2)),
      (1.6, (0, 0, 3))]

We obtain ![Figure 1](/home/wilfrid/ms/PerfectEpidemics/python/image/figure1.png "Figure 1: free epidemic")
      
And now two further tests::
     
     >>> rem = [[1.0], [0.1], [0.2], [0.3], [1.1, 2.0]]
     >>> ill = [[[0.5], [0.6], [0.7], [1.2]], 
     ...        [[], [], []], 
     ...        [[0.9], [2.1]],
     ...        [[3.0]]]
     >>> iv =Innovations(remove=rem, infect=ill)
     >>> epidemic = FreeEpidemic(innovations=iv)
     >>> pprint(epidemic())
     [(0, (4, 1, 0)), (1.1, (4, 0, 1))]

We obtain Figure 2. ![Figure 2](/home/wilfrid/ms/PerfectEpidemics/python/image/figure2.png "Figure 2: free epidemic")
 
     
     >>> rem = [[1.0], [1.2], [1.3], [1.5], [1.1, 2.0]]
