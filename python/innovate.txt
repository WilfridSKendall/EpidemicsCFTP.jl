Here is a typical invocation of the 'innovation' class::

     >>> from pprint import pprint
     >>> from innovate import Innovation

     >>> innovations = Innovation(remove=[[1, 1.6], [1.3], [0.5, 2]],
     ...                  infect=[[[0.4, 0.9], [0.6, 1.4]],
     ...                          [[0.2, 1.1, 1.5]]])

     >>> print(str(innovations))
     [[1, 1.6], [1.3], [0.5, 2]]
     [[[0.4, 0.9], [0.6, 1.4]], [[0.2, 1.1, 1.5]]]

     >>> pprint(innovations.epidemic())
     [(0, (2, 1, 0)),
      (0.4, (1, 2, 0)),
      (0.6, (0, 3, 0)),
      (1, (0, 2, 1)),
      (1.3, (0, 1, 2)),
      (2, (0, 0, 3))]
     
And now a rather more extensive test::
     
     >>> rel = [[1.0], [0.1], [0.2], [0.3], [1.1, 2.0]]
     >>> ill = [[[0.5], [0.6], [0.7], [1.2]], 
     ...        [[], [], []], 
     ...        [[0.9], [2.1]],
     ...        [[3.0]]]
     >>> innovations =Innovation(remove=rel, infect=ill)
     >>> pprint(innovations.epidemic())
     [(0, (4, 1, 0)),
      (0.5, (3, 2, 0)),
      (0.6, (2, 3, 0)),
      (0.7, (1, 4, 0)),
      (1.0, (1, 3, 1)),
      (2.1, (0, 4, 1))]
